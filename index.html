Same Die, Two Rules

Throw the die, then draw one step on each side by tapping the next grid point. Or let the machine do it with Auto throw. A: the roll picks one of three directions. B: the roll picks one of three turns. Same die, same three options, same odds. Only B remembers.

Three directions, 120° apart, so the average is zero and A never drifts on purpose. Each throw picks a direction from scratch. The random number is the value. No memory.

Rule B · Relativeroll → angle added to the last direction
123456 −60°−60°0°0°+60°+60°

Three angles: −60° is one grid line to the left, +60° one to the right. B starts pointing up. The random number is not a direction, it is an amount added to the last direction. That is the only difference from A.
